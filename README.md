# HiewDee — แพลตฟอร์มตัวกลางรับหิ้วของ

จับคู่ **คนอยากได้ของ** กับ **นักเดินทางที่รับหิ้ว** ทั้งของนอกและของในประเทศ
โดยแอปทำหน้าที่เป็นตัวกลางถือเงินไว้ (escrow) จนกว่าของจะถึงมือผู้ฝาก

> โปรเจกต์นี้เขียนด้วย Flutter + Riverpod เพื่อใช้เป็นผลงานในพอร์ตโฟลิโอ

---

## จุดที่ตั้งใจโชว์

### 1. Guest-first — ดูก่อน สมัครทีหลัง
เปิดแอปมาใช้งานได้ทันทีโดยไม่ต้องล็อกอิน ผู้ใช้จะเจอกำแพงล็อกอิน
ก็ต่อเมื่อกดปุ่มที่ต้องมีตัวตนจริงๆ เท่านั้น (แนวทางเดียวกับ Shopee/Lazada)

| ทำได้เลยแบบไม่ล็อกอิน | ต้องล็อกอินก่อน |
|---|---|
| ดูฟีดคำขอทั้งหมด | ฝากหิ้ว / โพสต์คำขอ |
| ดูรายละเอียดคำขอ | เสนอราคารับหิ้ว |
| ดูทริปนักหิ้ว + คะแนนรีวิว | แชทกับอีกฝ่าย |
| ค้นหาและกรองตามหมวด/ประเทศ | บันทึกคำขอ |
| เข้าแท็บ "ออเดอร์" และ "ฉัน" | เห็นเนื้อหาในแท็บนั้น |

**สิ่งสำคัญคือไม่ redirect ทั้งหน้า** — ระบบเด้ง bottom sheet ให้ล็อกอินตรงนั้น
พอเสร็จแล้ว action ที่ค้างไว้ทำงานต่อทันที ผู้ใช้ไม่หลุดออกจากสิ่งที่กำลังทำ

ดูโค้ดได้ที่ `lib/core/router/auth_gate.dart`:

```dart
// กดปุ่ม "ฝากหิ้ว" ในฟีด
final address = await ref.ensureAddress(
  context,
  reason: 'เข้าสู่ระบบเพื่อฝากหิ้วของ',
);
if (address != null && context.mounted) {
  context.push(AppRoutes.requestNew);
}
```

`ensureAddress` จะไล่ทำให้เองเป็นทอดๆ: ล็อกอิน → ถ้ายังไม่มีที่อยู่ก็พาไปกรอก →
คืนที่อยู่กลับมาให้ใช้ต่อ ถ้าผู้ใช้ยกเลิกกลางทางจะได้ `null` แล้ว flow หยุดเงียบๆ

### 2. ฟอร์มที่อยู่แบบไทยจริง
- ข้อมูลเขตการปกครองครบทั้งประเทศ **7,436 ตำบล** อยู่ใน `assets/data/thai_geo.json`
- ตัวเลือกแบบไล่ระดับ จังหวัด → เขต/อำเภอ → แขวง/ตำบล พร้อมช่องค้นหาทุกชั้น
- เลือกตำบลแล้ว **เติมรหัสไปรษณีย์ให้อัตโนมัติ**
- กรุงเทพฯ ถูกดันขึ้นบนสุดเสมอ ที่เหลือเรียงตามตัวอักษรไทย
- มีป้ายกำกับ (บ้าน / ที่ทำงาน / อื่นๆ) และการตั้งที่อยู่เริ่มต้น

### 3. บัญชีเดียว สองบทบาท
ผู้ใช้คนเดียวเป็นได้ทั้งผู้ฝากและนักหิ้ว ไม่ต้องสมัครสองรอบ —
กด "เปิดโหมดนักหิ้ว" ครั้งเดียวจบ (`ensureCarrier`)

### 4. เครื่องคำนวณภาษีนำเข้าตามเกณฑ์จริง
หัวใจของโปรเจกต์ — ลอจิกล้วนๆ ที่เขียนเทสต์ครอบได้เต็ม

- แยกสองช่องทางที่ให้ผลต่างกันมาก: **หิ้วติดตัว** (ยกเว้นถึง 20,000 ฿/คน/เที่ยว)
  กับ **ส่งไปรษณีย์** (ยกเว้น CIF ไม่เกิน 1,500 ฿)
- คำนวณ **VAT ทับอากร** อย่างถูกต้อง — ฐาน VAT คือ `CIF + อากร + สรรพสามิต`
  ไม่ใช่ราคาสินค้าเปล่า ซึ่งเป็นจุดที่คนคำนวณผิดกันมากที่สุด
- ค่าหิ้วคิดจาก `max(ฐานน้ำหนัก, ฐานมูลค่า)` ไม่ใช่บวกกัน
  พร้อมน้ำหนักปริมาตร `กว้าง×ยาว×สูง ÷ 5000`
- หักภาษีต้นทางที่ขอคืนได้ โดย **ถอดออกจากราคาที่รวมภาษีแล้ว**
  (`ราคา × r / (1+r)`) ไม่ใช่คูณตรงๆ
- ค่าธรรมเนียมชำระเงินคิดแบบ **gross-up** เพื่อให้ยอดสุทธิครบตามที่ตั้งไว้
- สิทธิยกเว้น 20,000 ฿ ถูกใช้ร่วมกันข้ามออเดอร์ในทริปเดียว

ดู `lib/features/pricing/` และเทสต์ 50+ เคสใน
`test/customs_rules_test.dart` กับ `test/pricing_engine_test.dart`

### 5. โมเดลการเงินที่นักหิ้วไม่ควักเงินตัวเอง
`lib/features/payments/domain/funding_policy.dart`

ความเสี่ยงถูกย้ายจากนักหิ้วมาไว้ที่แพลตฟอร์ม แล้วคุมด้วยเครื่องมือแทน:

| ลักษณะร้าน | วิธีจ่าย | เงินที่นักหิ้วออกเอง |
|---|---|---|
| ร้านออนไลน์ | แพลตฟอร์มจ่ายร้านโดยตรง | 0 ฿ |
| ร้านรับบัตร | บัตรเสมือนใช้ครั้งเดียว วงเงินตายตัว | 0 ฿ |
| ร้านเงินสด | โอนล่วงหน้าเต็มจำนวน + เงินค้ำตามระดับ | 0 ฿ |

คุมความเสี่ยงด้วยขั้นบันได KYC (`CarrierTier`) ที่กำหนดเพดานเงินสด
และหน่วงเวลาถอนเงิน — **ต้นทุนคืนให้เร็ว แต่กำไรจับไว้จนจบงาน**
เพื่อให้การทำงานให้จบคุ้มกว่าการเชิดของ

## เทคโนโลยีที่ใช้

| ส่วน | เลือกใช้ | เหตุผล |
|---|---|---|
| State management | `flutter_riverpod` | compile-safe, ทดสอบง่ายด้วย `ProviderContainer` |
| Routing | `go_router` | รองรับ `StatefulShellRoute` สำหรับ bottom nav ที่จำ state แต่ละแท็บ |
| ชั้นข้อมูล | Repository + interface | ตอนนี้เป็น mock ในหน่วยความจำ สลับไป Supabase ได้โดย UI ไม่ต้องแก้ |

## โครงสร้างโปรเจกต์

```
lib/
├── core/
│   ├── router/       app_router · app_routes · auth_gate  ← หัวใจของ guest-first
│   ├── theme/        app_colors · app_theme
│   └── utils/        formatters (เงินบาท, วันที่ พ.ศ., เบอร์โทร)
├── shared/widgets/   app_badges · auth_required_view
└── features/
    ├── auth/         โทรศัพท์ + OTP (mock)
    ├── address/      สมุดที่อยู่ + ตัวเลือกพื้นที่ไทย
    ├── request/      ฟีด · รายละเอียด · ฟอร์มโพสต์คำขอ
    ├── trip/         ทริปนักหิ้ว + พื้นที่คงเหลือ
    ├── carrier/      หน้าเปิดโหมดนักหิ้ว
    ├── orders/       แท็บออเดอร์
    ├── profile/      แท็บ "ฉัน"
    └── home/         โครง bottom navigation
```

แต่ละ feature แยกเป็น `domain/` (โมเดลล้วน) · `data/` (repository + provider) ·
`presentation/` (หน้าจอ + widget)

## วิธีรัน

```bash
flutter pub get
flutter run -d chrome     # หรือ -d windows / อุปกรณ์ Android
```

ถ้าใช้เบอร์ `0812345678` จะได้บัญชีตัวอย่างที่มีรีวิวและยอดเงินในกระเป๋าอยู่แล้ว
